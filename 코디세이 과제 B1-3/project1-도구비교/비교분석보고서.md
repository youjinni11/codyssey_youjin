# 프로젝트 1: 자동화 도구 비교 구현 보고서

## 1. 사용한 도구
- **Make** (구 Integromat)
- **Zapier**

## 2. 구현한 워크플로우 개요
동일한 업무를 두 도구에서 각각 구현했습니다.

- **Trigger**: Gmail에 새 메일이 도착
- **조건 분기**: 메일 제목/본문의 키워드에 따라 "일정 관련" / "업무 관련" 두 갈래로 분기
- **Action**: 분기별로 Discord DM 전송 (일정 관련 알림 / 업무 확인 알림)

## 3. 도구별 구현 과정 요약

### Make
- `Gmail (Watch Emails)` 트리거 → `Router` (2개 분기) → 각 분기별 `Discord (Send a Message)` 액션 순으로 하나의 시나리오 안에 구성했습니다.
- Router 모듈 하나로 조건 분기 전체를 한 화면에서 관리할 수 있었습니다.
- 실행 결과: Router의 두 분기(1st, 2nd) 모두 정상 실행되었고, Discord에 각각 알림 메시지가 도착한 것을 확인했습니다.

### Zapier
- Zapier 무료/체험판 플랜에서는 하나의 Zap 안에서 다중 분기(Paths)를 자유롭게 쓰기 어려워, 동일한 Trigger(`Gmail New Email`)를 가진 Zap을 **2개(자동화_1, 자동화_2)**로 나누어 구현했습니다.
- 각 Zap에 `Filter by Zapier`로 조건(제목에 특정 키워드 포함)을 걸고, `Discord (Send Direct Message)` 액션을 연결했습니다.
- 두 Zap 모두 Publish하여 상시 실행되도록 설정했고, 각각 테스트 실행으로 정상 동작을 확인했습니다.

## 4. 비교 항목

| 비교 항목 | Make | Zapier |
|---|---|---|
| UI/UX | 캔버스 기반 시각적 노드 편집. 전체 흐름이 한눈에 보임 | 세로 리스트형 스텝 편집. 직관적이지만 여러 Zap으로 나뉘면 전체 그림 파악이 어려움 |
| 설정 난이도 | 모듈 간 데이터 매핑(칩 삽입), 함수 사용 등 초기 학습 곡선이 있음 | 단계별 가이드가 친절해 진입장벽이 낮음 |
| 조건 분기 방식 | Router 모듈로 하나의 시나리오 내에서 다중 분기 처리 가능 | 무료/기본 플랜에서는 Filter만 지원되어, 다중 분기는 별도 Zap으로 쪼개거나 유료 Paths 기능이 필요 |
| 연동 서비스 범위 | Gmail, Discord, Google Calendar, Anthropic Claude 등 다양한 커넥터 지원 | 9,000개 이상의 앱과 연동, 매우 폭넓은 생태계 |
| 무료 플랜 범위 | 매월 1,000 Operations 무료 제공 | 무료 플랜은 100 Tasks/월 및 일부 기능 제한, 신규 가입 시 14일 Professional 무료 체험 제공 |
| 실행 로그 확인 방식 | 시나리오 실행 후 모듈별 Input/Output, 에러 메시지를 상세히 확인 가능 (Operation 단위) | Zap Test 단계에서 Data in/out을 실시간으로 확인 가능, 실행 후 Zap History에서 재확인 가능 |

## 5. 장단점 정리

### Make
- **장점**: 하나의 시나리오에서 복잡한 분기와 여러 액션을 한 화면에서 설계할 수 있어 전체 흐름 파악과 유지보수가 편합니다. 함수(mid, indexOf 등)를 활용해 데이터를 세밀하게 가공할 수 있습니다.
- **단점**: 초기 학습 곡선이 있고, 함수 작성 시 문법 오류(따옴표, 괄호 등)에 취약합니다. 에러 메시지가 다소 기술적이어서 초보자에게는 진입장벽이 될 수 있습니다.

### Zapier
- **장점**: 인터페이스가 단순하고 단계별 가이드가 친절해 빠르게 결과물을 만들 수 있습니다. Filter 조건 설정이 직관적입니다.
- **단점**: 무료/기본 플랜에서는 하나의 Zap 안에서 다중 분기가 제한되어, 동일한 로직도 여러 Zap으로 쪼개야 하는 번거로움이 있습니다.

## 6. 상황별 적합성 의견
- 복잡한 데이터 가공, 여러 갈래의 조건 분기, 다양한 서비스 간 정교한 연동이 필요한 업무라면 **Make**가 더 적합하다고 판단됩니다. 하나의 화면에서 전체 흐름을 관리할 수 있어 유지보수가 편합니다.
- 반대로 빠르게 단순한 자동화(예: A가 발생하면 B를 실행)를 시험적으로 구축하고 싶다면 **Zapier**가 진입장벽이 낮아 적합합니다. 다만 조건 분기가 여러 개 필요한 경우, Zap을 여러 개로 나누는 설계가 필요하다는 점을 감안해야 합니다.

## 7. 유료 기능 관련 안내
- Zapier의 `Filter by Zapier` 기능은 신규 가입 시 제공되는 14일 Professional 무료 체험판 내에서 사용했습니다. 체험 기간 종료 후 무료 플랜에서는 제한될 수 있어, 무료 대안으로 Zap을 여러 개로 나누어 각각 단일 조건의 Trigger로 구성하는 방식(자동화_1, 자동화_2로 분리 구현)을 사용했습니다.
